# ShiftMate ER

A lightweight emergency department shift management application.

## Live Demo

https://shaheenahmed1990.github.io/ShiftMate-ER/

## Features

- Shift management
- Cases, Tasks, Notes and Reminders
- Handover management
- Arabic / English
- RTL / LTR
- Light / Dark themes
- Local data storage
- Responsive interface

## Tech Stack

- React
- Vite
- Tailwind CSS
